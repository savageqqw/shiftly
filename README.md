# Shiftlyhnh

Персональний трекер робочого графіку: базовий цикл (напр. 5/2) з ручними
замінами по днях, облік відпрацьованих годин (з—до, разом) і кількості
товару, опрацьованого на трейд-ін за зміну.

## Стек

- Frontend: Vue 3 + Vite + Pinia + vue-router
- Backend: Vercel Serverless Functions (Node.js, ESM)
- База даних: Turso / libSQL
- Автентифікація: email + пароль, JWT

## Локальний запуск

1. Встановіть залежності:
   ```
   npm install
   ```
2. Створіть базу на [Turso](https://turso.tech) (безкоштовного плану достатньо):
   ```
   turso db create shiftly
   turso db show shiftly --url
   turso db tokens create shiftly
   ```
3. Скопіюйте `.env.example` у `.env` і заповніть `TURSO_DATABASE_URL`,
   `TURSO_AUTH_TOKEN` та довільний `JWT_SECRET`.
4. Запустіть у режимі розробки через Vercel CLI (потрібен для serverless
   функцій `/api`):
   ```
   npm i -g vercel
   vercel dev
   ```

## Деплой на Vercel

```
vercel --prod
```

Додайте змінні середовища (`TURSO_DATABASE_URL`, `TURSO_AUTH_TOKEN`,
`JWT_SECRET`) у налаштуваннях проєкту на vercel.com → Settings →
Environment Variables, або через `vercel env add`.

## Як це працює

- При першому вході сайт пропонує створити єдиний обліковий запис
  (email + пароль).
- У **Налаштуваннях** задається базовий цикл — скільки днів поспіль
  робочих, скільки вихідних, і від якої дати рахувати цикл.
- У **Графіку** кожен день можна відкрити і: залишити як є (за
  автоматичним циклом), примусово зробити робочим або вихідним
  (заміна), внести час з—до (години рахуються автоматично) та
  кількість одиниць товару, опрацьованого на трейд-ін.
- У **Статистиці** — підсумки за тиждень / місяць / увесь час: сумарні
  години, кількість змін, середня тривалість зміни, товар на трейд-ін
  і графік годин за тижнями.
